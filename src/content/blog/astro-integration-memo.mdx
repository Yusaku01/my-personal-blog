Astroで個人ブログを作るときに役立ちそうなインテグレーションや運用のメモ。
今の時点で「よく使うもの」「気になっているもの」「更新フローの課題感」をまとめておく。

## すでによく使うインテグレーション

- **astro-rss**
  - RSSフィードの生成に便利で、まず最初に入れることが多い。
- **astro-sitemap**
  - サイトマップ生成はSEOの基礎。RSSと並んで初期構成に入れがち。
- **astro-check**
  - ビルド前に簡易チェックできるので、作業の安心感が増える。
- **MDX**
  - Markdownだけだと表現が足りない場面があるので、MDXを入れて拡張性を確保する。

## これから試したいもの（気になっている）

- **Astro OG**
  - 公式インテグレーションにあるOG画像生成関連。
  - いまは日本語改行の都合で自前実装が多いけど、もっとシンプルにできるなら試したい。
- **astro-seo**
  - OG画像を補うものではないけれど、SEOまわりの整備として一度見ておきたい。
- **テーマ切り替え（ライト/ダーク/システム）**
  - Astroテーマのパッケージがあれば採用したいが、現状は自前実装の可能性が高い。
- **View Transitions時のローディング表示**
  - View Transitionsは使っているので、読み込み中がわかるエンジケーターがあると良さそう。
  - パッケージがあれば検討したい（なければ自作）。

## 更新フローの課題と改善メモ

このブログはコンテンツコレクションを使っていて、**.md/.mdx を編集できる環境がないと更新しづらい**。

- PCで編集できるなら問題ないが、
  **スマホから気軽に更新できる環境があるとハードルが下がる**。
- 最近は **Codex / Code on the Web などのAIエージェント**が出てきて、
  ターミナル操作やGit操作もスマホからできるようになってきた。
  1年前と比べるとかなり改善している。

それでも、
- **モバイル特化のビジュアルエディタ**
- **車の画面でも編集できるくらいのUI**

があった方が、更新のモチベーションには良い影響がある気がする。

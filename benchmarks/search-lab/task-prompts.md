# 検索の操作課題

答えはこのページに載せていません。各検索方式のページを開き、自分ならどう探すか考えてから検索してください。1課題につき2分を目安にし、答えが見つからない場合も記録します。

1. Web Worker から画面の要素を直接書き換えられるか確認してください。
2. Astro のビルド用キャッシュが既定で保存される場所を調べてください。
3. Lukurauha に読み込ませたファイルがサービスのサーバーへ送られるか調べてください。
4. Astro のリンク先を先読みする既定のタイミングを調べてください。
5. Astro の route caching が何を保存する機能か調べてください。
6. このブログから Astro 8 の正式リリース日を調べてください。
